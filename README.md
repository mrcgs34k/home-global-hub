# home-global-hub

本仓库用于归档和发布多个独立 HTML 页面。这些页面为静态内容，不依赖于特定域名或后端服务，适合作为通用页面集合进行维护与分发。

## 项目简介

`home-global-hub` 是一个轻量级的静态页面归档仓库。其核心目的是将若干独立、自包含的 HTML 文件集中管理，并可通过 GitHub Pages 或其他静态托管服务直接访问。仓库不绑定任何具体网站或应用，仅作为页面文件的存储与发布节点。

## 目录结构

```
├── index.html          # 仓库入口页（可选）
├── pages/              # 存放主要 HTML 页面
│   ├── page1.html
│   ├── page2.html
│   └── ...
├── assets/             # 公共资源（样式、脚本、图片等）
│   ├── css/
│   ├── js/
│   └── images/
└── README.md           # 本文件
```

- `pages/`：所有独立 HTML 页面存放于此，每个文件可独立访问。
- `assets/`：页面共享的静态资源，按类型组织。
- `index.html`：可选，作为仓库根目录的入口页面。

## 页面归档说明

- 每个 HTML 页面均为独立文件，内部包含完整的样式与脚本引用（可依赖 `assets/` 中的资源）。
- 页面之间无强依赖关系，可单独部署或更新。
- 归档内容不涉及任何具体域名、品牌或商业推广信息。

## 使用方式

1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/your-username/home-global-hub.git
   ```
2. 在 `pages/` 目录下添加或修改 HTML 文件。
3. 若启用 GitHub Pages，仓库根目录或 `docs/` 文件夹中的内容将自动发布为静态站点。

## 维护说明

- 新增页面请放置在 `pages/` 目录下，并确保文件命名清晰、无重复。
- 公共资源如有更新，请同步更新 `assets/` 中对应文件，避免破坏已有页面。
- 提交代码前建议本地预览，确保页面功能正常。
- 本仓库不存储敏感信息，所有内容均为公开静态文件。
